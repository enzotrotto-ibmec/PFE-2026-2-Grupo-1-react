# Projeto para AP2 da disciplina Projeto Front-end

## PKZ Lab & One to One

Repositório de organização e centralização do código produzido para o projeto de avaliação AP2 da disciplina Projeto Front-end, cujo objetivo é desenvolver o novo site da empresa PKZ Lab & One to One utilizando React.

## Contexto

A PKZ Lab & One to One contratou nossa instituição para reestruturar o site da empresa. Na etapa anterior (AC), o site foi desenvolvido em HTML, CSS e JavaScript puro (Vanilla). Nesta etapa (AP2), o foco está em reconstruir o site utilizando React, com publicação no Vercel.
